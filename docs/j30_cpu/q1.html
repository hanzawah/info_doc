ポイント解説

この問題は、コンピュータを構成する基本的な5つの装置（五大装置）の役割を問うています。 下の図は、五大装置の基本的な関係性を表したものです。

graph TD %% スタイル定義 classDef device fill:#f0f8ff,stroke:#444,stroke-width:2px,font-weight:bold,font-size:16px classDef cpu fill:#fff0f0,stroke:#c00,stroke-width:2px classDef memory fill:#e6f3ff,stroke:#004080,stroke-width:2px %% 全体の構成 Input(入力装置) --> MainMemory(主記憶装置) MainMemory --> Output(出力装置) MainMemory <--> AuxMemory(補助記憶装置) MainMemory <==> CPU %% CPUの内部構造 subgraph CPU direction LR Control(制御装置) ALU(演算装置) Register(レジスタ) %% CPU内部の流れ Register <--> ALU Control --> ALU Control --> Register end %% スタイルの適用 class Input,Output,Control,ALU,Register device class MainMemory,AuxMemory memory class CPU cpu linkStyle default stroke-width:1px,stroke:gray

問題文の会話と、この図を照らし合わせると、以下のようになります。

  • い (制御装置): 命令を解読し、各装置へ指示を出す司令塔���
  • ろ (演算装置): 実際に計算を行う装置。
  • は (入力装置): 外部からデータを取り込む。
  • に (出力装置): 結果を外部に表示する。

これらの組み合わせが一致する選択肢、②が正解となります。
