正解: ウ:①, エ:⓪, オ:②

ポイント解説

CPUが命令を実行する流れ（命令実行サイクル）は、いくつかの段階に分かれています。この問題は、その詳細なステップを問うています。 特に、命令を実行するために必要なデータ（オペランド）を主記憶から取ってくる「データの取り出し」がどの段階で行われるかがポイントです。

問題文の図と、一般的な命令実行サイクルを照らし合わせると、以下のようになります。

  • 命令を取り出した後、CPUはその命令が何をするものなのかを理解する必要があります。これがウ：命令の解読 (Decode) です。
  • 次に、命令の実行に必要なデータを主記憶から取ってくる必要があります。これがエ：データの取り出し (Operand Fetch) です。
  • データが揃ったら、演算装置(ALU)が実際に処理を行います。これがオ：命令の実行 (Execute) です。

したがって、正解は ウが「① 命令の解読」、エが「⓪ データの取り出し」、オが「② 命令の実行」 の組み合わせとなります。

【参考】ノイマン型アーキテクチャ（プログラム内蔵方式）とは？

CPUが実行すべき命令（プログラム）と、その処理対象となるデータを、区別せずに同じ主記憶装置（メモリ）上に格納し、逐次処理していく方式です。この特徴から「プログラム内蔵方式（Stored Program Computer）」とも呼ばれます。 詳細はノイマン型（Wikipedia）も参照してください。

現代のほとんどのコンピュータは、このノイマン型アーキテクチャを基本としています。プログラムをデータと同様にメモリへ読み込んで実行するため、ソフトウェアを入れ替えるだけで多様な処理を行えるという、高い柔軟性と汎用性を実現しています。
