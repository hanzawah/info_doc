問1: OS (Operating System)

コンピュータのハードウェアとソフトウェアを管理し、人間が直感的に操作できるように仲介する基本的なソフトウェアです。代表的なOSにはMicrosoft社の「Windows」やApple社の「macOS」などがあります。アプリケーションは特定のOS向けに開発されるため、利用したいソフトウェアがどのOSに対応しているかを確認することが重要です。

問3: CPU (Central Processing Unit)

コンピュータの「頭脳」に相当する部分で、あらゆる計算や制御の中心的な役割を担います。CPUの性能は、動作の速さを示す「クロック周波数(GHz)」や、同時に処理できる作業量を表す「コア数」で判断するのが一般的です。これらの数値が大きいほど、複雑な計算や多くの作業を高速に処理できます。

問4: ストレージ (記憶装置)

作成したファイルやアプリケーションなど、データを長期間保存しておくための場所です。主に「SSD」と「HDD」の2種類があり、それぞれに特徴があります。

SSD (Solid State Drive)

USBメモリと同じように、半導体メモリを使ってデータを読み書きする記憶装置です。物理的に回転するディスクを持つHDDとは異なり、機械的な駆動部分がありません。そのため、以下のような多くのメリットがあります。

  • 高速な動作: データの読み書き速度がHDDに比べて圧倒的に速く、OSやアプリケーションの起動、ファイルの読み込みが劇的に高速化されます。
  • 高い耐久性: 物理的な駆動部品がないため、衝撃や振動に強く、故障のリスクが低いです。持ち運びの多いノートパソコンには特に適しています。
  • 静音性: 動作音がほとんどなく、静かな環境での使用に向いています。
  • 低消費電力: HDDよりも消費電力が少ないため、ノートパソコンのバッテリー駆動時間を延ばす効果も期待できます。

近年、価格が下がってきたこともあり、多くのパソコンで主要なストレージとして採用されています。

HDD (Hard Disk Drive)

磁気ディスクを高速で回転させ、データを記録する記憶装置です。SSDに比べて、容量あたりの単価が安いのが最大のメリットで、大容量のデータを低コストで保存するのに向いています。動画や写真など、大量のデータを保存したい場合に、外付けHDDとして活用されることも多いです。

問5: インターフェース

コンピュータ本体と周辺機器（ディスプレイ、キーボード、マウス、外部ストレージなど）を接続するための規格や端子の総称です。代表的なインターフェースには以下のようなものがあります。

  • USB (Universal Serial Bus): 最も普及しているインターフェースで、様々な機器の接続に利用されます。近年は、より高速で多機能な「USB Type-C」が主流になりつつあります。
  • HDMI (High-Definition Multimedia Interface): 映像と音声を1本のケーブルで伝送できる規格で、主にディスプレイやテレビへの出力に用いられます。
  • イーサネット (Ethernet): 有線でインターネットに接続するためのポートです。安定した高速通信が可能です。
