1. はじめに：バブルソートとは？

バブルソートは、たくさんのソートアルゴリズムの中でも、最もシンプルで理解しやすいアルゴリズムの一つです。プログラミング学習の第一歩として、アルゴリズムの基本的な考え方（「比較」と「交換」）を学ぶのに最適です。

名前の由来は、水中の泡（バブル）が水面に上がっていく様子に似ていることから来ています。このアルゴリズムでは、隣り合う2つの要素を比べて、もし順序が逆だったら場所を交換します。この操作を何度も繰り返すことで、一番大きい（または小さい）要素が、まるで泡のように配列の端に「浮かび上がって」いくのです。このセクションでは、その基本的な仕組みと考え方を学びます。

2. 体験する：バブルソートの動きを見る

ここでは、バブルソートが実際にどのように動くのかを、アニメーションで体験できます。データ数や速度を調整したり、自分でデータを入力して、アルゴリズムの動きを観察してみましょう。右側のコードのどの部分が実行されているかもハイライトで表示されます。

Python コード


def bubble_sort(arr):
  n = len(arr)
  for i in range(n):
    swapped = False
    for j in range(0, n - i - 1):
      if arr[j] > arr[j + 1]:
        arr[j], arr[j+1] = arr[j+1], arr[j]
        swapped = True
    if not swapped:
      break
  return arr
操作を開始してください。

3. なぜ遅いの？ 計算量 O(N²) を知る

バブルソートはシンプルですが、データが多くなると急激に遅くなるという特徴があります。これを「計算量がO(N²)である」と表現します。Nはデータの数です。これは、データ数が2倍になると、処理にかかる時間（比較回数）が約4倍（2の2乗）になることを意味します。

下のスライダーを動かしてデータ数(N)を増やしてみてください。比較回数がどのように増えていくか、グラフで体感できます。

比較回数 (最悪の場合):

45

(N * (N - 1) / 2)

4. どう改善する？ バブルソートの最適化

基本的なバブルソートは非効率ですが、少し工夫するだけで性能を改善できます。ここでは代表的な2つの最適化手法を紹介します。上のビジュアライザで「最適化を有効化」にチェックを入れると、これらの手法が適用された動きを確認できます。

早期終了 (Early Termination)

もし、あるパス（配列の最初から最後までの一回の走査）で一度も交換が行われなかったら、それは配列がすでに完全にソートされていることを意味します。その時点でソート処理を終了することで、不要な比較を省くことができます。特に、ほとんどソート済みのデータに対して非常に効果的です。


def bubble_sort_optimized_1(arr):
    n = len(arr)
    for i in range(n):
        swapped = False  # 交換フラグ
        for j in range(0, n - 1):
            if arr[j] > arr[j + 1]:
                arr[j], arr[j+1] = arr[j+1], arr[j]
                swapped = True
        if not swapped:  # 交換がなければループを抜ける
            break
    return arr

ソート範囲の縮小

1回のパスが完了すると、その時点で未ソート部分の最大値が配列の正しい位置に確定します。つまり、次のパスでは、その確定した要素を比較対象から外すことができます。パスごとに比較する範囲を一つずつ狭めていくことで、全体の比較回数を減らすことができます。


def bubble_sort_optimized_2(arr):
    n = len(arr)
    for i in range(n):
        # ループの範囲が n - i - 1 となっている
        for j in range(0, n - i - 1):
            if arr[j] > arr[j + 1]:
                arr[j], arr[j+1] = arr[j+1], arr[j]
    return arr

※注: 2つの最適化は、体験セクションの「最適化を有効化」チェックボックスで同時に適用されます。コードは統合されたものが使われています。

5. 他のアルゴリズムとの比較

バブルソートはアルゴリズム学習の入り口です。世の中にはもっと高速で効率的なソートアルゴリズムがたくさんあります。それぞれのアルゴリズムがどのような特徴を持つのかを知ることで、状況に応じて最適な手法を選択する力が身につきます。

アルゴリズム名 平均計算量 最悪計算量 安定性 特徴
バブルソート O(N²) O(N²) 安定 実装が簡単。教育用に最適。
選択ソート O(N²) O(N²) 不安定 交換回数が少ない。
挿入ソート O(N²) O(N²) 安定 ほぼソート済みのデータに高速。
マージソート O(N log N) O(N log N) 安定 どのようなデータでも安定して高速。
クイックソート O(N log N) O(N²) 不安定 一般的に最も高速だが、最悪の場合がある。
