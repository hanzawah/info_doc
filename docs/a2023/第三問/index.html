第3問：アルゴリズムとデータ構造（スケジューリング問題）

この問題は、塾の講師のシフト割り当てを題材に、最適な割り当て（総講師数を最小化）を見つけ出すアルゴリズムを設計・理解する問題です。2次元配列（行列）を用いて情報を管理し、それを更新していく手続き（アルゴリズム）の読解力が問われます。

問1：2次元配列の操作

基本的な情報の読み取りと、2次元配列の更新手続きに関する問題です。

ア、イ：表からの情報抽出

  • アの考察: 表1は、各時限を一人だけで担当する講師の人数を示しています。講師数が最も多いのは、対角要素が最大である第3時限で、その人数は19人です。よってアは3。
  • イの考察: 同様に、講師数が最も少ないのは、対角要素が最小である第5時限で、その人数は7人です。よってイは5。

ウ、エ、オ：手続きの読解

図1の手続きは、「`ninzu`人の講師が`kaisi`時限と`kaisi+1`時限を連続で担当する」という操作を担当表`Hyou`に反映させるものです。

  • 思考プロセス:
    1. この操作により、新しく「`kaisi`時限に開始し、`kaisi+1`時限に終了する」講師が`ninzu`人追加されます。これは、(03)の `Hyou[ウ, エ] ← オ` に対応し、ウ:① kaisi, エ:② kaisi+1, オ:④ ninzu となります。
    2. 連続担当する分、「`kaisi`時限のみ担当」と「`kaisi+1`時限のみ担当」の講師は不要になります。
    3. (04)で `Hyou[kaisi, kaisi]` から、(05)で `Hyou[kaisi+1, kaisi+1]` から、それぞれ`ninzu`人減らします。

解答: ウ:①, エ:②, オ:④

カ：操作による総数の変化

この手続きを1回実行すると、講師の総数はどう変化するでしょうか？

  • `Hyou[kaisi, kaisi]` から `ninzu` 人減る。(-ninzu)
  • `Hyou[kaisi+1, kaisi+1]` から `ninzu` 人減る。(-ninzu)
  • `Hyou[kaisi, kaisi+1]` に `ninzu` 人追加される。(+ninzu)
  • 合計の変化は `-ninzu - ninzu + ninzu = -ninzu` となります。
  • つまり、1回の操作で、出勤する講師の総数は `ninzu` 人だけ減少します。

解答: カ:④

問2：アルゴリズムの設計（ループと条件分岐）

指定された時限帯（`hajime`から`owari`）で連続担当可能な講師数の上限（ボトルネック）を見つけ出すアルゴリズムを完成させます。

キ、ク、ケ、コ：最小値探索アルゴリズム

この手続きの上限は、期間中の各時限で必要な講師数（対角要素）の最小値によって決まります。

  • (03) `saisyou ← キ`: 最小値探索の基本として、まず最初の値 `Hyou[hajime, hajime]` を「仮の最小値」とします。よってキ:⑤ Hyou[hajime,hajime]。
  • (05) `もし ク > ケ ならば`: 「仮の最小値 `saisyou`」と「次の時限の講師数 `Hyou[i,i]`」を比較します。よってク:③ saisyou, ケ:⑨ Hyou[i,i]。
  • (06) `saisyou ← コ`: もし新しい最小値が見つかれば、`saisyou`をその値 `Hyou[i,i]` で更新します。よって、`コ`には`ケ`と同じ`⑨ Hyou[i,i]`が入るのがアルゴリズムとして適切です。

解答: キ:⑤, ク:③, ケ:⑨, コ:⑨
※大学入試センターの正解はコ:③ですが、アルゴリズムとして正しく機能させるにはコ:⑨が適切です。

サ：ループ実行回数

`hajime`に1, `owari`に5が入力された場合、(04)のループは `i` を `1+1=2` から `5` まで、つまり `i` = 2, 3, 4, 5 の4回実行されます。

解答: サ:4

問3：最適化アルゴリズムの実装

作成した部品を組み合わせ、全体の講師数を最小化する最適化アルゴリズムを完成させます。これは、最も長い連続担当から順に割り当てていく「欲張り法」の一種です。

シ、ス：ループ範囲の決定

連続時限数が4の場合、考えられる組み合わせは「1〜4時限」と「2〜5時限」の2通りです。問題文の「【1, シ】と【ス, 5】」に対応させます。

  • 【1, シ】: 開始が1で連続4時限なので、終了は4。よってシ: 4。
  • 【ス, 5】: 終了が5で連続4時限なので、開始は2。よってス: 2。

解答: シ:4, ス:2

ソ、タ、チ、ツ：アルゴリズムの穴埋め

図3のアルゴリズムは、`renzoku`（連続時限数）を5から2まで減らしながら、各連続時限について集約を繰り返す構造です。

  • (04) `owari ← ソ`: `owari`は`hajime`と`renzoku`から決まります (`owari = hajime + renzoku - 1`)。ループ内で`hajime`と`owari`は連動して1ずつ増えます。(03)で`hajime`が1に初期化されるため、`owari`の初期値は`renzoku`であるべきです。よってソ:② renzoku。
  • (05) `owari タ JIGENSU`: ループの継続条件です。`owari`が全体の時限数`JIGENSU`を超えない間、処理を続けます。よってタ:① <=。
  • (13) `Hyou[hajime, チ] ← saisyou`: (06)-(11)で求めた最大可能人数`saisyou`を、担当表の `Hyou[hajime, owari]` に記録します。よってチ:⑥ owari。
  • (15) `Hyou[i,i]を ツ 減らす`: 連続担当に割り当てた`saisyou`人分、各時限の単独担当者を減らします。よってツ:⑦ saisyou。

解答: ソ:②, タ:①, チ:⑥, ツ:⑦
※大学入試センターの正解はソ:③ですが、アルゴリズムとして正しく機能させるにはソ:②が適切です。

テ、ト：最終結果の読み取り

アルゴリズムを表5に適用した最終結果が表7です。表7の【2,3】と【3,4】の値を読み取ります。

  • テ（【2,3】の値）: 表7の2行3列は 0 です。
  • ト（【3,4】の値）: 表7の3行4列は 5 です。

解答: テ:0, ト:5
