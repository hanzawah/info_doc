第1問

問1：情報社会における基本的な知識

この問題は、情報社会で必須となる基本的な用語の理解度を問うています。単に用語を暗記するだけでなく、それぞれの技術がどのような場面で、なぜ必要なのかを理解することが重要です。

a. アクセス制御

正解: ⓪ アクセス制御

クラウドストレージ上のファイルに対して、誰が「閲覧」や「編集」ができるかを設定する機能はアクセス制御の典型例です。重要なのは、許可されたユーザー（やグループ）だけが意図した操作を行えるようにし、それ以外のユーザーからの不正なアクセスを防ぐことです。これは、企業の機密情報や個人のプライバシーを守るための根幹技術です。

発展: アクセス制御モデルには、任意アクセス制御（DAC）、強制アクセス制御（MAC）、役割ベースアクセス制御（RBAC）など、様々な種類があります。例えば、Google Driveの共有設定はRBACの一種と考えることができます。

b. Webアクセシビリティ

正解: ② Webページをブラウザの音声読み上げ機能に対応できるように修正した

Webアクセシビリティとは、年齢や身体的な条件に関わらず、誰もがWebサイトやサービスを問題なく利用できるようにすることです。選択肢②は、視覚に障がいを持つ人が音声読み上げソフトを使って情報を得られるようにする対応であり、アクセシビリティ向上のための具体的な取り組みです。

発展: アクセシビリティ��確保するための国際的なガイドラインとして、WCAG (Web Content Accessibility Guidelines) があります。画像の代替テキスト（alt属性）の提供、キーボードのみでの操作の保証、十分なコントラスト比の確保などが求められます。

c. 可逆圧縮

正解: ③ 圧縮したデータを伸張(展開)すると圧縮前と全く同じになる

ZIPは可逆圧縮（ロスレス圧縮）方式の代表例です。これは、データを圧縮しても、展開（伸張）すれば完全に元の状態に戻せることを意味します。文書ファイルやプログラムなど、1ビットの情報欠損も許されないデータの圧縮に用いられます。

計算と思考プロセス:

  • 元のデータ量: 4.5 Mバイト = 4.5 * 1000 kバイト = 4500 kバイト
  • 圧縮後のデータ量: 2160 kバイト
  • 削減できたデータ量: 4500 - 2160 = 2340 kバイト
  • 削減率: (削減できたデータ量 / 元のデータ量) * 100 = (2340 / 4500) * 100 = 52% (エオ)

発展: 画像（PNG）、音声（FLAC）などにも可逆圧縮が使われます。一方、JPEG（画像）やMP3（音声）は非可逆圧縮（ロッシー圧縮）で、人間の知覚しにくい部分のデータを削除することで高い圧縮率を実現しますが、完全には元に戻りません。

d. データ通信量

計算と思考プロセス:

  1. 1日の視聴に必要なデータ量を計算する
    • 通信速度: 2 Mbps (メガビット/秒) = 2,000,000 bps
    • 1日の視聴時間: 2時間 = 2 * 60 * 60 = 7200 秒
    • 1日のデータ量(ビット): 2,000,000 bps * 7200 s = 14,400,000,000 ビット
  2. ビットをバイトに変換する
    • 8 ビット = 1 バイト
    • 1日のデータ量(バイト): 14,400,000,000 / 8 = 1,800,000,000 バイト
  3. 単位をGバイトに合わせる
    • 1 Gバイト = 1000 Mバイト = 1000 * 1000 kバイト = 1,000,000,000 バイト
    • 1日のデータ量(Gバイト): 1,800,000,000 / 1,000,000,000 = 1.8 Gバイト
  4. 視聴可能な日数を計算する
    • 利用可能なデータ量: 18 Gバイト
    • 視聴可��日数: 18 Gバイト / 1.8 Gバイト/日 = 10日 (カキ)

注意: 問題文の `1G = 1000M` という定義に注意が必要です。一般的なOSでは `1GB = 1024MB` (2^10) で計算されることが多いため、問題の指示に正確に従うことが重要です。

問2：ディジタルデータの表現

この問題は、音、画像といったアナログ情報をどのようにディジタルデータとして表現するか、その方式と特徴についての理解を問います。

a. データ形式の分類

正解: (A)ク:② 音楽CD, (B)ケ:⓪ BMP, (C)コ:③ ベクター(ベクトル)

  • (A) 音の表現: 音楽CDで使われるPCM方式は、音の波形を一定時間ごとにサンプリング（標本化）し、その振幅を量子化して記録する代表的な方式です。MIDIは音の設計図であり、波形そのものではありません。
  • (B) 画像（ラスタ形式）: BMPは、画像をピクセル（画素）の集まりとして、各ピクセルの色情報をそのまま記録する非圧縮のラスタ（ビットマップ）形式です。
  • (C) 画像（ベクタ形式）: ベクター形式は、画像の構成要素を点、線、多角形などの図形の数式（座標、色、大きさなど）で表現します。

b. ラスタ形式とベクタ形式の比較

正解: サ:③ 画像を拡大した場合に(C)と異なり(B)はジャギー(ギザギザ)が表示されることがある。

ラスタ形式とベクタ形式の最も本質的な違いは、拡大・縮小時の品質です。

  • ラスタ形式 (B): ピクセルの集まりなので、拡大するとピクセル自体が大きくなり、画像の輪郭がギザギザに見える「ジャギー」が発生します。
  • ベクタ形式 (C): 数式で表現されているため、拡大・縮小の際は再計算されるだけで、画質が劣化しません。ロゴやイラストなど、様々なサイズで利用される画像に適しています。

他の選択肢の検討:

  • ⓪: 夕焼けのような複雑な階調を持つ写真は、ピクセル単位で色を表現するラスタ形式(B)の方が適しています。
  • ①: BMP(B)は通常、非圧縮です。圧縮する場合でも可逆圧縮が一般的です。
  • ②: ラスタ形式(B)は解像度が高くなる（ピクセル数が増える）と、データ量が飛躍的に増加します。ベクタ形式(C)は図形の複雑さによりますが、解像度の概念はありません。

問3：文字コード

コンピュータ内部で文字をどのように表現しているかを問う問題です。2進数、16進数、そして文字の対応関係を正確に読み解く能力が求められます。

文字コードの解読

この問題の文字コード表は、上位3ビットで行を、下位4ビットで列を指定する構造になっています。

  • セの解読:
    • 2進数コード `0000010` を、問題の指示通り上位3ビットと下位4ビットに分割します。
    • 上位3ビット: `000` → 表の行見出し `0`
    • 下位4ビット: `0010` → 表の列見出し `2`
    • 文字コード表の`0`行`2`列を確認すると、文字は大文字の`C`です。
    • 解答群を見ると、選択肢①が`C`となっているため、これが正解です。（なお、文字コードでは大文字の`C`と小文字の`c`は区別されることに注意が必要です。）
  • ソの解読:
    • 文字`$`を探します。表の5行C列にあります。
    • 行の見出しは`5`なので、上位3ビットは`101`。
    • 列の見出しは`C`(16進数)なので、下位4ビットは`1100`。
    • 結合すると `1011100` となります。正解: ⑦
  • タの考察:
    • 四則演算子は `+`, `-`, `×`, `÷` です。表の5行目、0, 1, 2, 3列にあります。
    • これらの文字コードの上位3ビットはすべて`5`(`101`)です。下位4ビットが`0`から`3`に変化します。
    • 選択肢を検証すると、①「文字コードの上位3ビットが101である」が、これらの演算子に共通する特徴を最も的確に捉えています。
  • チの考察:
    • 大文字と小文字の関係を見ます。例: `A`(0行0列)と`a`(2行0列)、`B`(0行1列)と`b`(2行1列)。
    • `A`のコード: `0000000`
    • `a`のコード: `0100000`
    • `B`のコード: `0000001`
    • `b`のコード: `0100001`
    • いずれのペアも、上位3ビットの2ビット目（左から2番目）が`0`から`1`に変わる（あるいは`010`を加算する）と小文字になり、下位4ビットは同じです。
    • この関係を最も正確に表現しているのは、③「上位2ビット目を1にすると小文字、0にすると大文字になる」です。
